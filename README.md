# Tourism 360

## About the Project
Tourism 360 is a tourism website designed to explore India's famous tourist destinations,
discover attractions across different states and union territories,
and learn about local culture and heritage.

## Features
- Explore tourist destinations across India.
- Discover historical and cultural attractions.
- View destination details.
- Plan your trips.
